# Omarchy GitHub Stats

Personal GitHub activity and open work presented in an Omarchy bar widget.

## Language

**Contribution**:
An activity GitHub counts in the account's contribution calendar. Contributions include more than commits and are subject to GitHub's eligibility and visibility rules.
_Avoid_: Commit, when referring to the calendar's total activity

**Contribution heatmap**:
A date-based arrangement of tiles whose intensity represents the contribution activity on each day.
_Avoid_: Commit chart

**Selected period**:
The span shown in Stats: the last 7 days, 30 days, or 12 months, ending today. The chart and period activity summaries cover the same span.

**Today**:
The current UTC calendar date used for the widget's GitHub contribution view.

**Commit contribution**:
A commit GitHub counts as a contribution within the selected period. This is not a count of every commit in the user's local or accessible repositories.
_Avoid_: Lifetime commits, total Git commits

**Authored PR**:
A pull request created by the signed-in account. Its creation contributes to period activity regardless of whether the PR remains open.

**Review request**:
A pending request to review an open PR, addressed either to the signed-in account or to a team that includes that account.

**Authored issue**:
A GitHub issue created by the signed-in account. Its creation contributes to period activity regardless of whether the issue remains open.

**Assigned issue**:
A GitHub issue whose assignees include the signed-in account.

**Open issue**:
A GitHub issue in the open state. Pull requests are excluded, even where GitHub APIs expose both through related issue types.

**Repository scope**:
Repositories personally owned by the signed-in account, including public and accessible private repositories and excluding forks. Organization-owned repositories are outside this scope.

**Stars**:
The current sum of stars received by repositories in the repository scope. This is a snapshot, not the number of stars ever received or gained during the selected period.
_Avoid_: Stars given, period stars

**Repository languages**:
The distribution of GitHub-reported language bytes across the repository scope. It describes repository contents rather than coding time, expertise, or language use during the selected period.
_Avoid_: Most used languages, coding time

**Notification**:
A GitHub notification thread for the signed-in account, about activity on a subject such as a PR, issue, release, discussion, or CI run.
_Avoid_: Alert, message

**Inbox**:
The account's notifications that are not marked done, both unread and read.
_Avoid_: Feed, notification list

**Unread notification**:
A notification with activity the account has not yet viewed. Opening it makes it read; it stays in the Inbox until marked done.

**Done**:
The state of a notification removed from the Inbox. It returns when its thread has new activity.
_Avoid_: Dismiss, archive, delete, clear

**Unsubscribe**:
Stop notifications for a thread until the account comments on it or is mentioned. Notifications from watching the repository continue.
_Avoid_: Mute, ignore

**Subscribe**:
Resume notifications for a thread.

**Notification reason**:
Why GitHub notified the account about a thread, such as a review request, a mention, or CI activity.
